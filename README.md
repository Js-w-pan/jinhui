# 金汇 · 黄金、白银与欧元观察

手机和电脑可用的 GitHub Pages 行情工具。沿用金汇的绿色界面、清晰字体和共用访问密码。

## 功能

- 黄金 Au99.99、白银 Ag(T+D)、欧元 EUR/CNY，各有独立历史数据。
- 近1周、1月、3月、1年、5年、10年，以及自定义起止日期。
- 价格折线、MA20、每日涨跌幅柱图、月度涨跌热力图。
- 周、月、年统计日历，点击日期查看详情，与走势图联动。
- 最高、最低、均价、最大回撤、年化波动率和 CSV 导出。
- 七家银行的公开报价入口；有可验证数据才显示价格。银行历史按官方发布日期保存每日最后一次成功采样，不补造历史。

## 首次上线

1. 将本项目文件（包括 `.github/workflows/market-pages.yml`）上传到 `main`。
2. 打开 **Settings → Secrets and variables → Actions → New repository secret**。
3. 名称填写 `JINHUI_PASSWORD`，值填写当前金汇网站的共用访问密码。不要把密码写进源码、README 或仓库文件。
4. 打开 **Settings → Pages**，将 **Source** 改为 **GitHub Actions**，无需域名。
5. 打开 **Actions → 更新行情并发布金汇 → Run workflow → main → Run workflow**。
6. 发布任务出现绿色勾后访问 https://js-w-pan.github.io/jinhui/ 。

已经生成的 `index.html`、`app.js`、`style.css`、`favicon.svg` 和 `data/market.enc.json` 也能直接由现有的 `main / (root)` 方式发布快照版。但只有配置上述自动任务后，行情才会持续更新。

## 自动更新

GitHub Actions 计划每小时第17分钟采集，成功采样加密保存到仓库并重新发布。网页每5分钟检查已经发布的结果，也支持手动刷新。关闭网页不影响后台计划任务。

GitHub 的计划任务可能延迟；公共仓库长时间（官方规则为60天）无活动时可能停用计划任务。若页面提示检查时间超过36小时，查看 Actions，必要时启用并手动运行。任务失败不会替换线上已发布版本。所有来源都失败时仍保留已有记录，并记录各来源错误。

## 密码和访问

行情文件使用 PBKDF2-SHA256（600000次）和 AES-256-GCM 加密；浏览器使用输入的密码解密，密码不发送到行情源、不保存在浏览器存储，也不写入仓库。刷新整页需要重新输入密码，“退出访问”清除内存中的解密密钥。

这是共享密码的静态加密访问方式，不具备服务器登录的限速、单人撤销或账号管理功能。持有密码的人可以查看并转发。源码和所引用的银行/交易所公开数据本身不是保密资料。请勿在此网站保存银行账户或其他私人资料。

不能仅修改 GitHub Secret 来更换网站密码：旧行情需要先用旧密码解密、用新密码重新加密，再同时更新 Secret。已经下载的旧数据不能远程撤销。

## 本地开发

Node.js 24 或以上；`npm install`，`npm test`，`npm run build`。更新源码后需要重新构建并提交 `app.js`。定时任务直接运行原生 Node.js 采集脚本，不依赖外部字体、图表 CDN 或原 ChatGPT 站点。

发布时 `scripts/package-site.mjs` 只复制六类网页资源；源码、测试、工作流和开发文件不包含在网站发布包中。
